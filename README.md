Features

1. Sorting Algorithms in C

The "1.c" program demonstrates three sorting techniques:

- Bubble Sort
- Selection Sort
- Insertion Sort

The program uses an array of size 5 and provides a menu-driven interface to display the array and perform the available sorting operations.

The program also keeps track of:

- Number of passes
- Number of comparisons

2. Python Agent

The "agent.py" file contains a simple Python program that prints numbers from 1 to 5.

# Print numbers from 1 to 5
for number in range(1, 6):
    print(number)

3. Contribution Documentation

The "contribution log.md" file is used to maintain a record of development and contribution activities carried out during the project.

Sorting Algorithms

Bubble Sort

Bubble Sort repeatedly compares adjacent elements and swaps them when they are in the wrong order.

Selection Sort

Selection Sort searches for the appropriate element and places it in its correct position in the array.

Insertion Sort

Insertion Sort builds the sorted portion of the array one element at a time by inserting each element into its appropriate position.
